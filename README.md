# Icog-MM2-Task

This repository contains two MM2/MeTTa logic programming demonstrations:

## 1. FizzBuzz3.metta
- Implements the classic FizzBuzz problem using Peano numbers and rule-based logic in MM2.
- Demonstrates recursion, pattern matching, and arithmetic in a logic programming style.
- To run: `./target/debug/mork run FizzBuzz3.metta`

## 2. GraphTraversal.metta
- Demonstrates graph traversal using a stateful, step-by-step recursion style in MM2.
- Shows how to represent a graph, and step through the graph like a process, keeping explicit state at each step.
- Due to MM2/MORK limitations, this version only explores one step from the start node. 
- To run: `./target/debug/mork run GraphTraversal.metta`
